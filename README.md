# aws-learning-lab

AWS を学びながら、実際に試した手順・失敗・考えたことを残すための学習ログです。

このリポジトリは完成済みの正解集ではなく、`tyz8250` が AWS を触りながら理解していく過程を、あとから第三者が読んでも追える形で整理することを目的にしています。

## このリポジトリで残すこと

- 手順: 何を、どの順番で操作したか
- 概念理解: その操作が AWS 上で何を意味するか
- つまずいた点: エラー、勘違い、調査したこと
- セキュリティ上の注意: 公開範囲、権限、鍵、ログ
- 削除・課金対策: 学習後に何を消すか、何が課金対象か
- 構成図: 作った構成を図で確認できるようにする
- 学び: 次に活かすメモ

## 使い方

1. 各ディレクトリの番号順に読む
2. 実際に作業したら、各ファイル末尾の「試行ログ」に日付つきで追記する
3. エラーや失敗は消さずに、原因と対応を追記する
4. 学習が終わったら、必ず「削除・課金対策」を確認する

### セキュリティメモの扱い

以下は GitHub に載せないでください。

- AWS アクセスキー、シークレットアクセスキー
- 秘密鍵ファイル、秘密鍵の中身
- MFA の復旧コード
- 個人情報、電話番号、メールアドレス
- グローバル IP アドレスを固定で公開する必要がない場合の自宅 IP
- アカウント ID を公開したくない場合のスクリーンショット

## 学習前チェック

- ルートユーザーに MFA を設定した
- IAM ユーザーまたは IAM Identity Center の利用を検討した
- AWS Budgets を設定した
- 使い終わったリソースを削除する前提で作業する
- セキュリティグループで `0.0.0.0/0` を開ける意味を理解する
