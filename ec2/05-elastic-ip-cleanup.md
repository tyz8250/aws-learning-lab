# 05. Elastic IP とクリーンアップ

## 目的

Elastic IP の役割と課金ポイントを理解し、学習で作った EC2 関連リソースを削除する。

## 前提

- EC2 を作成済み
- 必要に応じて Elastic IP を割り当て済み
- AMI やスナップショットを作成した場合は一覧を確認できる

## 手順

1. Elastic IP の割り当て状態を確認する
2. 不要なら EC2 から関連付けを解除する
3. Elastic IP を解放する
4. EC2 インスタンスを終了する
5. EBS ボリュームが残っていないか確認する
6. AMI を登録解除する
7. EBS スナップショットを削除する
8. セキュリティグループ、キーペア、CloudWatch Logs などの残存を確認する

## 概念理解

Elastic IP は固定のパブリック IPv4 アドレスです。インスタンスを停止・起動しても同じ IP を使いたい場合に便利ですが、未使用状態や構成によって課金対象になります。学習では「便利だけど残すと課金につながるリソース」として特に注意します。

## つまずいた点

- EC2 を消しても Elastic IP が残ることがある
- AMI とスナップショットの削除を忘れやすい
- リージョンをまたいでリソースを確認する必要がある

## セキュリティ上の注意

- 不要な固定 IP は解放する
- セキュリティグループに不要な公開ルールを残さない
- キーペアの管理状況を確認する

## 削除・課金対策

確認対象:

- EC2 インスタンス
- EBS ボリューム
- EBS スナップショット
- AMI
- Elastic IP
- Load Balancer
- NAT Gateway
- CloudWatch Logs
- AWS Budgets の通知

## 学び

- AWS 学習は「作る」より「消す」までを 1 セットにする
- 固定 IP、スナップショット、ログは残りやすい
