# 01. AWS Budgets を設定する

## 目的

学習中の予期しない課金に早く気づけるように、AWS Budgets で予算と通知を設定する。

## 前提

- AWS アカウントにログインできる
- 通知を受け取るメールアドレスを決めている
- 学習で使う月額上限の目安を決めている

## 手順

1. Billing and Cost Management を開く
2. Budgets を開く
3. コスト予算を作成する
4. 月額の予算額を設定する
5. しきい値を設定する
6. 通知先メールアドレスを設定する
7. 確認メールが来た場合は承認する
8. Cost Explorer で実績を確認する

## 概念理解

AWS Budgets は、利用料金や使用量が設定したしきい値に近づいたときに通知するサービスです。課金を完全に止める機能ではなく、早く気づくための仕組みです。

## つまずいた点

- Budgets は自動停止ではない
- 通知メールの承認が必要な場合がある
- 料金反映には時間差がある

## セキュリティ上の注意

- 請求情報にアクセスできる権限をむやみに広げない
- 予算通知先のメールアドレスを間違えない
- ルートユーザーの請求アクセス設定も確認する

## 削除・課金対策

- Budgets を設定しても、リソース削除は別途必要
- Cost Explorer でサービス別料金を見る
- EC2、EBS、Elastic IP、S3、CloudWatch Logs、NAT Gateway を重点的に確認する

## 学び

- AWS 学習では、最初に Budgets を作る
- 通知は安全装置であり、削除作業の代わりにはならない
