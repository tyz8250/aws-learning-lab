# 03. GuardDuty を試す

## 目的

GuardDuty を有効化し、AWS アカウントやワークロードに対する脅威検知の考え方を理解する。

## 前提

- AWS アカウントにログインできる
- 課金の可能性を理解している
- 学習後に無効化するか継続利用するか決める

## 手順

1. GuardDuty を開く
2. サービスを有効化する
3. 検出結果のサンプルを生成する
4. どのような Finding が出るか確認する
5. 重大度、リソース、推奨対応を読む
6. 学習後、継続利用するか無効化するか判断する

## 概念理解

GuardDuty は CloudTrail、VPC Flow Logs、DNS ログなどを分析し、不審な操作や通信を検知するマネージド脅威検知サービスです。自分で検知ルールを一から作るのではなく、AWS 側の知見を使ってリスクを見つけます。

## つまずいた点

- 有効化するだけで何が監視されるのか分かりにくい
- サンプル Finding と実際の Finding の区別が必要
- リージョンごとに有効化状態を確認する必要がある

## セキュリティ上の注意

- Finding を見つけたら、対象リソースと操作履歴を確認する
- 検知は防御そのものではないため、IAM やネットワーク制御も必要
- 通知や対応フローを考えないと、検知しても見逃す

## 削除・課金対策

- 無料トライアル期間や料金条件を確認する
- 継続利用しない場合は無効化する
- 複数リージョンで有効化していないか確認する

## 学び

- セキュリティサービスは「有効化」だけでなく「見て対応する」までが必要
- Finding の読み方に慣れることが大事
