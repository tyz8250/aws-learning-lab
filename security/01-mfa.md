# 01. MFA を設定する

## 目的

AWS アカウントの不正利用リスクを下げるため、ルートユーザーや重要な IAM ユーザーに MFA を設定する。

## 前提

- AWS アカウントにログインできる
- 認証アプリまたはハードウェア MFA を準備している

## 手順

1. AWS コンソールにログインする
2. セキュリティ認証情報を開く
3. MFA デバイスを割り当てる
4. 認証アプリで QR コードを読み取る
5. 連続する 2 つの認証コードを入力する
6. サインアウトして MFA が求められることを確認する

## 概念理解

MFA はパスワードに加えて、手元のデバイスによる認証を要求する仕組みです。パスワードが漏れても、MFA があることで不正ログインの難易度を上げられます。

## つまずいた点

- ルートユーザーと IAM ユーザーの設定場所が違う
- 認証アプリの時刻ずれでコードが通らないことがある
- 復旧方法を考えずに設定すると、端末紛失時に困る

## セキュリティ上の注意

- ルートユーザーには必ず MFA を設定する
- 復旧手段を安全な場所に保管する
- MFA コードや復旧コードを GitHub に載せない

## 削除・課金対策

MFA 自体に通常の利用料金はかかりません。ただし、ハードウェア MFA を使う場合はデバイス購入費が発生します。

## 学び

- AWS 学習の最初に MFA を設定する
- ルートユーザーは緊急時用として扱う
