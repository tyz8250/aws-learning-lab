# 02. CloudTrail を確認する

## 目的

AWS アカウント内で誰が、いつ、どの API 操作をしたか確認できるようにする。

## 前提

- AWS アカウントにログインできる
- 学習用リージョンを決めている

## 手順

1. CloudTrail を開く
2. イベント履歴を確認する
3. EC2 の作成や停止など、自分の操作が記録されているか見る
4. 必要に応じて証跡を作成する
5. S3 バケットにログを保存する場合、バケット名と保存期間を決める

## 概念理解

CloudTrail は AWS API 操作の監査ログです。コンソール操作も内部的には API として記録されます。何か問題が起きたときに、操作履歴を追うための基本的なサービスです。

## つまずいた点

- イベント履歴と証跡の違いが分かりにくい
- 全リージョン対象にするか、単一リージョンにするか迷う
- S3 に保存したログにも保管コストがかかる

## セキュリティ上の注意

- CloudTrail を無効化する操作は慎重に扱う
- ログ保存先 S3 バケットの公開設定に注意する
- ログ改ざんを防ぐ設定も検討する

## 削除・課金対策

- 証跡を作った場合は S3 バケットとログ量を確認する
- 学習用なら保存期間を決める
- 不要な証跡や S3 バケットを削除する

## 学び

- AWS では「何をしたか」をあとから追える状態にしておく
- セキュリティ学習ではログを見る習慣が重要
